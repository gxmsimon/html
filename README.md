## 🚀 部署教程（Cloudflare Pages）
1. 将本仓库上传至 GitHub
2. 进入 Cloudflare Pages → 创建项目，绑定该GitHub仓库
3. 构建预设框架选择：`None`
4. 构建命令：留空
5. 输出目录填写：`.` （根目录）
6. 保存并部署，等待构建完成即可访问
